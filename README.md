# Sayyar 🚐


- Sayyar is a ride/commute marketplace connecting captains (drivers), commuters (riders), and partners, with a production-ready Django backend and modular frontends.

## Tech stack 


### Backend: 
- Python (3.x),  
- Django 5.1.5, 
- Django REST Framework, 
- djangorestframework-simplejwt, 
- Firebase Admin SDK, 
- Google Cloud client libraries (Google maps),
- PostgreSQL; 


### Frontend: 

Flutter, Dart
